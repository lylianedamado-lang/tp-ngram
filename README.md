# TP: Modèle de langage basé sur les N-grammes

Mini modèle de langage statistique construit en Python (bibliothèque standard uniquement), à partir d'un petit corpus. Il illustre toute la chaîne : corpus, tokenisation, N-grammes, comptages, probabilités, puis applications NLP (prédiction du mot suivant, génération, probabilité d'une phrase, correction contextuelle, lissage de Laplace).

## Lancer le programme

```bash
python3 main.py
```

Un menu interactif propose 11 options (vocabulaire, N-grammes, prédiction, génération, correction, etc.).

## Structure

- `modele.py` : tout le modèle (tokenisation, N-grammes, probabilités, prédiction, génération, correction, Laplace).
- `main.py` : le menu interactif.
- `REPONSES.md` : les réponses aux questions théoriques du TP.
